# College Value Predictor

Interactive app that predicts whether a US college is "high value"
built on College Scorecard data. (Live app link coming soon)

## Data
- **Source:** US Dept. of Education, College Scorecard, Most Recent Institution Level Data
- **Downloaded from:** https://collegescorecard.ed.gov/data/
- **Download date:** 2026-11-18 (Data last updated by Dept of Education on June 10, 2026
- Raw files aren't stored in this repo because of their size. To reproduce, download the files above into `data/raw/`.
